Crazy Hunter - Datenschutzerklärung

Stand: 23. November 2026

Diese Datenschutzerklärung erläutert, welche Informationen verarbeitet werden, wenn Sie Crazy Hunter (das „Spiel“, Android-Paketname com.crazyhunter.game) spielen. Herausgeber ist kalebilal-ux („wir“, „uns“).

Kurz gesagt:

  • Das Spiel hat keine Konten, keine Anmeldung und keine In-App-Käufe. Wir fragen weder nach Ihrem Namen, Ihrer E-Mail-Adresse, Telefonnummer, Ihren Kontakten oder Fotos noch nach Ihrem genauen Standort.
  • Wir betreiben keinen eigenen Server und erheben oder erhalten selbst keine personenbezogenen Daten.
  • Ihr Bestwert und Ihre Einstellungen werden ausschließlich auf Ihrem Gerät gespeichert.
  • Das Spiel ist kostenlos und zeigt Werbung über Google AdMob an. Um Werbung anzuzeigen und zu messen, erhebt die Google-Werbesoftware im Spiel bestimmte Gerätedaten, die unten beschrieben sind.

1. Auf Ihrem Gerät gespeicherte Informationen

Das Spiel speichert eine kleine Datenmenge im lokalen Speicher der App auf Ihrem Gerät: Ihren Bestwert, Ihre Einstellungen (etwa Ton) sowie die Information, ob der Tutorial-Hinweis im ersten Spiel bereits angezeigt wurde. Diese Daten verlassen Ihr Gerät durch uns nicht. Sie werden gelöscht, wenn Sie die App-Daten löschen oder das Spiel deinstallieren. Das Spiel liest die Spracheinstellung Ihres Geräts nur, um sich in Ihrer Sprache anzuzeigen; sie wird von uns weder gespeichert noch gesendet.

Das Spiel enthält das Google Mobile Ads SDK und das User Messaging Platform (UMP) SDK von Google. Sie können sie jederzeit widerrufen, wie in Abschnitt 5 beschrieben. 5. Ihre Wahlmöglichkeiten und der Widerruf der Einwilligung

  • Werbe-ID zurücksetzen oder löschen: Öffnen Sie auf Ihrem Android-Gerät Einstellungen → Google → Werbung (auf manchen Geräten Einstellungen → Datenschutz → Werbung) und wählen Sie Werbe-ID zurücksetzen oder Werbe-ID löschen. Nach dem Löschen können Apps die ID nicht mehr verwenden, um Ihnen personalisierte Werbung anzuzeigen.
  • Anzeigenpersonalisierung von Google deaktivieren: Besuchen Sie das Anzeigencenter oder adssettings.google.com.
  • Im Spiel erteilte Einwilligung ändern oder widerrufen: Wenn für Sie eine Einwilligungsabfrage gilt, können Sie die Einwilligungsoptionen jederzeit erneut öffnen, indem Sie oben auf dem Spielbildschirm auf die Schaltfläche Datenschutz tippen (das Spiel wird in der Sprache Ihres Geräts angezeigt, bei nicht unterstützter Sprache auf Englisch, und die Beschriftung richtet sich nach dieser Sprache; z. B. „Privacy“ oder „Gizlilik“). Alternativ können Sie die Daten des Spiels löschen (Einstellungen → Apps → Crazy Hunter → Speicher → Speicher leeren) oder das Spiel neu installieren; das Einwilligungsformular wird beim nächsten Start in einer Region, in der es erforderlich ist, erneut angezeigt. Beim Löschen der Daten wird auch Ihr gespeicherter Bestwert gelöscht. Auch das Löschen Ihrer Werbe-ID (siehe oben) beendet personalisierte Werbung.
  • Spielen, ohne dass Werbung geladen wird: Das Spiel funktioniert offline. Ohne Internetverbindung werden keine Anzeigen angefordert und keine Daten gesendet.
  • Lokale Daten löschen: Leeren Sie den Speicher der App oder deinstallieren Sie das Spiel.
